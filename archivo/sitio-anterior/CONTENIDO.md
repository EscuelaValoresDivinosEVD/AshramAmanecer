# Contenido del sitio actual — ashramcaminantesdelamanecer.com (WordPress + Divi)

Extraído el 2026-09-23 de las 32 URLs del sitemap (`urls.txt`). El texto de las páginas se copia **literal** (español, sin traducir ni resumir). Convenciones:

- `## / ### / ####…` = encabezados tal como aparecen en el HTML (Divi usa H1–H6 por estilo, no por jerarquía; un `H1` en el HTML aparece aquí como `##`, H2 como `###`, etc.).
- `![alt](url) "title: …"` = imagen `<img>` en esa posición (URL original a tamaño completo; alt casi siempre vacío en el sitio viejo; el "title" es el nombre del archivo en la mediateca).
- `![background](url) <!-- background of … -->` = imagen de fondo CSS de una sección/fila/columna/módulo de Divi.
- `[BUTTON: texto](destino)` = botón Divi; `[LINK: …]` = enlace suelto; `[IFRAME: …]` = embed (video/form).
- `<!-- (… HIDDEN on phone/tablet — responsive duplicate) -->` = bloque que Divi oculta en ciertos dispositivos: muchas páginas tienen **el mismo contenido dos veces** (versión escritorio y versión móvil). Al reconstruir, usar sólo una.
- `---` = separación entre secciones Divi.
- El footer (idéntico en todas las páginas) se ha quitado de cada página y se documenta una sola vez abajo.
- `images.txt` tiene la lista de todas las imágenes; las marcadas `[BROKEN: 404]` ya no existen en el servidor.
